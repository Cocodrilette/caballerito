**tu** juego y cómo convertirlo en lo que tú quieras.

y vuelve cuando quieras más. 🗡️🐶

## 🏅 Tu tabla de medallas

Cada vez que termines un reto, ¡márcalo en [retos.md](retos.md)

| Medalla | Nivel | Qué necesitas saber |

| 🐛 | Gusanito | Usar el editor de niveles, dibujar, componer |

## 🆘 Si algo se rompe

1. **No pasa nada.** Todos los programadores rompen cosas. Todo el tiempo.
2. Presiona **Ctrl + Z** en el editor de código para deshacer.
3. Mira el error: en el navegador presiona **F12** y abre la pestaña **Console**.
   El error dice el archivo y la línea donde está el problema.
4. Si nada funciona: `git checkout .` vuelve todo a la última versión guardada
   (mira el [capítulo 9](09-git.md)).
