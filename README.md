# Caballerito

Juego de plataformas 2D inspirado en Hollow Knight, hecho para aprender a programar.
Construido con [Kaplay](https://kaplayjs.com) + Vite + JavaScript. Todos los gráficos,
la música y los sonidos se generan desde código editable (sin archivos binarios).

```bash
npm install
npm run dev        # juego en /, editor de niveles en /editor.html, de dibujos en /sprites.html
npm run build      # versión estática en dist/
```

En Windows: doble clic en `JUGAR.bat`.
